# Коефіцієнт природного приросту — онлайн-платформа оцінювання економічної безпеки

Навчальна інтерактивна платформа для розрахунку **коефіцієнта природного приросту населення** (індикатор 2.4, демографічна складова) та визначення рівня економічної безпеки держави за Методичними рекомендаціями, затвердженими наказом Мінекономрозвитку України № 1277 від 29.10.2013.

**Онлайн-версія:** https://chayka1.github.io/pryrodnyi-pryrist/

**Виконав:** Чайка Максим Володимирович
**Дисципліна:** «Інформаційні технології у системі забезпечення економічної безпеки держави»

## Формула

$$K_{пп} = \frac{N - M}{S} \times 1000, \text{‰}$$

| Позначення | Зміст | Одиниця |
|---|---|---|
| **N** | кількість живонароджених за рік | осіб |
| **M** | кількість померлих за рік | осіб |
| **S** | середньорічна чисельність наявного населення | осіб |
| **K<sub>пп</sub>** | коефіцієнт природного приросту | ‰ (на 1 тис. осіб) |

Від'ємне значення означає природне скорочення населення (депопуляцію). Індикатор є **стимулятором** (нормується за лівою частиною шкали L): що вище значення, то вищий рівень економічної безпеки. Ваговий коефіцієнт індикатора — **0,1874** (додаток 3 до Методичних рекомендацій).

Рівень економічної безпеки визначається за **середнім арифметичним** річних значень коефіцієнта за досліджуваний період.

## Порогові значення

Характеристичні значення індикатора 2.4 (додаток 2 до Методичних рекомендацій):

| X<sub>L крит</sub> | X<sub>L небезп</sub> | X<sub>L нездв</sub> | X<sub>L здв</sub> | X<sub>L опт</sub> |
|:-:|:-:|:-:|:-:|:-:|
| −2 | −1 | 0 | 1 | 1,5 |

| Інтервал K<sub>пп</sub>, ‰ | Рівень економічної безпеки |
|:-:|---|
| [1,5; +∞) | Оптимальний |
| [1; 1,5) | Задовільний |
| [0; 1) | Незадовільний |
| [−1; 0) | Небезпечний |
| [−2; −1) | Критичний |
| (−∞; −2) | Абсолютна небезпека |

Квадратна дужка — межа входить до інтервалу, кругла — не входить.

## Можливості платформи

- **Покрокове введення даних:** країна → досліджуваний період (1–15 років) → вихідні дані за кожен рік.
- **Перевірка введених даних** з поясненням помилок безпосередньо біля поля:
  - порожні поля, літери, десяткові та від'ємні значення;
  - формат і діапазон років, послідовність періоду;
  - чисельність населення більша за 0 і не надто мала (захист від введення в тисячах замість осіб);
  - кількість народжених або померлих не перевищує чисельність населення;
  - правдоподібність значень (понад 60 ‰ вважається помилкою введення).
- **Розрахунок** коефіцієнта за кожен рік та середнього значення за період.
- **Визначення рівня економічної безпеки** за кожен рік і за період загалом.
- **Підсумкова таблиця**, шкала рівнів з позначкою результату та **графік** динаміки з кольоровими зонами рівнів.
- **Автоматичний аналітичний висновок:** рівень безпеки, приріст чи депопуляція, динаміка, найкращий і найгірший рік.
- **Пояснення** формули, одиниць виміру та порогових значень, посилання на джерело.
- **Експорт** результатів у CSV та друк / збереження у PDF.
- Вставлення даних стовпцями безпосередньо з Excel.
- Адаптивний дизайн (комп'ютер, планшет, телефон), світла й темна теми.

Розрахунок виконується локально в браузері — введені дані нікуди не надсилаються.
